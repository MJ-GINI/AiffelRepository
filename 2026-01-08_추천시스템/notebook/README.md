1. `data_EDA.ipynb`: 데이터 이해 및 분석
2. `data_prepro.ipynb`: 데이터 전처리 및 필수 파일(npy, pkl) 생성
3. `autoint_train.ipynb`: AutoInt 활용한 레이어 정의, 평가지표, 학습 및 평가 + 가중치 파일 저장
4. `autoint_mlp_train.ipynb`: AutoInt+ 활용한 레이어 클래스 재정의(수정), 학습 및 평가 + 가중치 파일 저장
5. `autoint_mlp_train_re.ipynb`: 지옥의 레이어 넘버링 늪에서 빠져나오기 위해 세션 / 모델 초기화 후, 재저장
6. `model_load_test.ipynb`: 스트림릿 실행 전, 생성된 가중치 로드 테스트
